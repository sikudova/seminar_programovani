# Cvičení 25: statistiky čísel

**Cíl:** aplikace `for` cyklu

Napiš program, který se nejprve zeptá uživatele, kolik čísel chce celkem zadat. Program pak postupně načte tato čísla a na konci spočítá a vypíše, kolik z nich bylo kladných, kolik záporných a kolik nulových.

```text
How many numbers do you want to enter: 7
Enter number 1: -6
Enter number 2: -7
Enter number 3: 4
Enter number 4: 0
Enter number 5: 0
Enter number 6: 8
Enter number 7: 13

== STATISTICS ===
Positive numbers: 3.
Negative numbers: 2.
Zeros: 2.
```
